# Анализ тональности текста (NLP Sentiment Analysis)

Нейросетевая модель для определения эмоциональной окраски текста (позитив/негатив/нейтрально). Проект включает полный цикл: от обучения модели до развертывания веб-приложения с удобным интерфейсом.

## Возможности
- Анализ тональности текста на русском и английском языках
- Интерактивный веб-интерфейс с мгновенной выдачей результата
- Визуализация уверенности модели в предсказании
- Оптимизированный инференс через ONNX для высокой скорости работы
- Готов к развертыванию через Docker

## Веб-интерфейс

Фронтенд на React.js предоставляет:
- Поле ввода текста с поддержкой многострочного ввода
- Отображение результата анализа с цветовой индикацией (зеленый — позитив, красный — негатив, серый — нейтрально)
- Индикатор уверенности модели (confidence score) в процентах
- Адаптивный дизайн для десктопов и мобильных устройств
- Примеры текстов для быстрого тестирования

API бэкенда на Flask обрабатывает запросы, передает текст в оптимизированную модель и возвращает результат с метриками уверенности.

## Стек технологий

**Машинное обучение:**
- TensorFlow — построение и обучение нейросети
- Архитектура: 2-branch CNN + LSTM + Attention
- ONNX — оптимизация модели для быстрого инференса

**Бэкенд:**
- Python Quart (асинхронный Flask)
- Hypercorn — ASGI-сервер
- REST API для взаимодействия с фронтендом

**Фронтенд:**
- React.js с функциональными компонентами
- Современный UI/UX дизайн

**Инфраструктура:**
- Docker — контейнеризация приложения
- Nginx — reverse proxy и раздача статики

## Метрики модели
- Precision
- Recall
- F1-мера

*Графики обучения и матрица ошибок в директории `/results`*
